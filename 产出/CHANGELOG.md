## v1.8.1

用户提出「提示词开头是不是该加身份，例如『你是一位经验丰富的 PPT 视觉设计大师』」。

调研后判定**不建议默认加**：身份句不排除任何候选方案（横竖版、受众、页数一个都没决定），「大师」还容易诱导模型往视觉炫技走、牺牲「每页一个结论」；且它与本插件规则 9「不堆通用套话」以及评估器 D5（persona 免责声明直接判失败）冲突。基础系统提示词首行的 `You are a senior engineer...` 是对**改写器**说的，与「输出给用户的提示词开头」是两回事，保持不变。

改为提供两件可核验的替代能力：

### 宝库：3 条演示稿验收口径

- `seed-des-04` 编辑级验收清单（字号层级 ≤3、每页一个结论、留白 ≥30%…）
- `seed-des-05` 结构先于装饰（先写行动句与页标题清单，再排视觉）
- `seed-des-06` 评审清单而非意见（逐条报页码、违反的规则、最小修法）

全部是**可核验的检查项**，不含「你是一位…」。

### 面板：可选「成稿规范」开关

- 4 个可勾选规范：演示稿 / 文档 / 代码 / 文案
- 只传 **key**，措辞由 Host 掌握；未知 key 一律丢弃，无法注入指令
- 默认全不选，**此时系统提示词与 v1.8.0 逐字节一致**，质量基线不受影响
- 新增 `lib/standards.js` 纯函数模块，`looksLikePersona()` 与配套测试保证生成的追加段永不出现角色扮演措辞

### 验证

- 230 条测试（v1.8.0 为 211 条），新增 19 条
- 质量门禁 55.9 vs 51.6，无回退

## v1.8.0

**插件更名为「许愿树」（Wish Tree）**，从单个输入框按钮升级为独立面板，并新增提示词宝库。

### 更名

- 显示名、面板标题、图标、全部用户文案改为「许愿树 / Wish Tree」
- npm 包名由 `dsh-prompt-enhancer` 改为 **`dsh-wish-tree`**
- locale 命名空间改为 `dsh-wish-tree`
- 面板内保留一次旧名提示，说明「原名『增强提示词』」
- **迁移提示**：包名变了，已安装用户需重新安装一次（旧包不会自动迁移）；仓库地址仍为 `spycai/dsh-prompt-enhancer`

### 新增：独立面板

- 侧栏面板图标 + `main` 面板视图（不再只是一个按钮或浮层）
- 面板内含：想法输入区、场景与受众选项、「生成」主按钮、结果区（复制 / 一键回填）、宝库入口
- 保留输入框小按钮作为**第二入口**，避免侧栏入口在宿主变化时无路可进
- 延续 v1.7.0 的订阅策略：渲染期只存 `ref`，点击时才读会话消息

### 新增：提示词宝库

- 内置 **25 条精选种子**，覆盖 6 个分类（通用 / 写作 / 编程 / 分析 / 设计 / 学习），**离线完全可用**
- 支持显示、搜索（多关键词全匹配）、分类筛选、收藏
- 可从 GitHub 公开来源刷新扩充（`f/prompts.chat` 的 `prompts.csv`）
- 每条记录保存 `source` / `sourceUrl` / `license` / `fetchedAt`
- **许可白名单硬约束**：只接受 `CC0-1.0` / `MIT` / `Apache-2.0` / `BSD-3-Clause` / `ISC`，其余整条丢弃
- 选中条目可作为「参考范式」注入，模型只借鉴结构、不复制主题
- 刷新失败一律回落到内置种子库，只改提示文案，不影响可用性

### 新增：场景与受众

- 6 个场景（通用 / 写作 / 编程 / 分析 / 设计 / 学习），5 个受众选项
- 仅以 **key** 传给 Host，措辞由 Host 掌握；无法识别的 key 一律忽略，不注入任何指令
- 不选时（`general` / `auto`）追加内容为空，**系统提示词与 v1.7.0 逐字节一致**

### 修复 / 保持

- 不动 `lib/context.js`、`lib/timeout.js` 与既有 `enhance` 路由行为
- 质量门禁标准未降低：`baseline:check` 仍为 55.9 vs 51.6，无回退

### 测试

- 210 条（v1.7.0 为 119 条），新增 91 条
- 新增模块：`wishlist`（20）、`seed`（7）、`sources`（20）、`panel-state`（22）、`library-route`（8）、面板契约（7）
