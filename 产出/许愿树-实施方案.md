### 1.1 为什么不改包名

改包名意味着：
- 所有已安装用户要重新装（旧包不会自动迁移）
- `cordis.patch.yml` 的行 `name` 必须同步，否则加载失败
- README/INSTALL/GitHub URL 全部失效

**决定**：包名保留 `dsh-prompt-enhancer`，**显示名全部改为「许愿树」**。用 CHANGELOG + 界面提示完成"更名"的用户可见部分。若将来要改包名，应单独发一个大版本并写迁移指南。

## 二、架构：从「按钮」到「面板」

### 2.1 现状

```
conversation.input.right  →  [魔棒按钮] → 菜单(专业提示词/仅润色) → 请求 → 回填
```

### 2.2 目标

```
sidebar.panellist  →  [许愿树图标]  ┐
                                    ├→ main(wish-tree) 面板
conversation.input.right → [🌳]  ───┘   （双入口，同一个面板）

面板布局：
┌─────────────────────────────────────────────┐
│  许愿树                          [旧名提示]  │
├─────────────────────────────────────────────┤
│  ① 想法                                      │
│  ┌─────────────────────────────────────────┐│
│  │ 做个PPT                                  ││
│  └─────────────────────────────────────────┘│
│                                              │
│  ② 场景  [通用▾]   受众 [同事▾]   ← 可选     │
│                                              │
│  ③ [ 生成 ]  ← 主按钮                        │
│                                              │
│  ④ 结果                                      │
│  ┌─────────────────────────────────────────┐│
│  │ 请制作一份面向公司内部同事的 PPT……       ││
│  └─────────────────────────────────────────┘│
│  [复制]  [回填到输入框]                      │
│                                              │
│  ⑤ 宝库  [搜索____]  [浏览][收藏]  [刷新]    │
│  ┌──────────┬──────────────────────────────┐│
│  │ 分类     │ 条目列表（标题/来源/许可）    ││
│  └──────────┴──────────────────────────────┘│
└─────────────────────────────────────────────┘
```

### 2.3 双入口的理由（重要）

`main` 是 keyed slot，`keyDomain` 提示「selected by sidebar entry id」，但**类型定义没有明确保证**点击 `sidebar.panellist` 图标会自动 dispatch 对应 key。

**风险控制**：
- 主入口：`sidebar.panellist` 图标 + `main` 面板（完整形态）
- 备用入口：保留 `conversation.input.right` 小按钮，点击直接**打开同一个面板**
- 若 `main` 面板无法通过点击图标唤起（真机验证失败），则降级为：
  - 按钮点击 → 用 `shell.overlay` 渲染全屏面板
  - 保留面板所有功能，只是宿主不同

**这个降级必须在真机验证阶段确认，不能假设。**

## 四、数据结构

### 4.1 宝库条目

```js
{
  id: 'pt-0001',              // 稳定 id，收藏用它
  title: 'Ethereum Developer', // 显示标题
  titleZh: '',                 // 可选中文标题
  category: 'code',            // 分类键
  tags: ['code', 'blockchain'],
  body: 'Imagine you are ...', // 提示词正文
  language: 'en',              // 'zh' | 'en'
  source: 'prompts.chat',      // 来源标识
  sourceUrl: 'https://github.com/f/prompts.chat/blob/main/prompts.csv',
  license: 'CC0-1.0',          // 必须是白名单内
  fetchedAt: '2026-11-15T00:00:00.000Z'
}
```

### 4.2 许可白名单（硬约束）

```js
const ALLOWED_LICENSES = new Set(['CC0-1.0', 'MIT', 'Apache-2.0', 'BSD-3-Clause', 'ISC'])
```

**解析时逐条校验**：`license` 不在白名单 → **整条丢弃**，并计入 `rejected` 计数。绝不让来路不明的内容进库。

### 4.3 收藏

```js
{ saved: ['pt-0001', 'pt-0042'], updatedAt: '...' }
```
只存 id，不复制正文 → 避免二次分发问题，也减小存储。

### 4.4 面板状态

```js
{
  idea: '',              // 想法输入
  scene: 'general',      // 场景键
  audience: 'auto',      // 受众键
  phase: 'idle' | 'busy' | 'done' | 'error',
  result: '',            // 生成结果
  error: '',
  library: {
    open: false,
    query: '',
    category: 'all',
    selectedId: null,
    source: 'seed' | 'remote',
    loading: false,
    notice: '',          // "离线，使用内置库" 等
  },
}
```

## 五、数据流

### 5.1 生成流程

```
用户输入想法 + 选场景/受众
        ↓
[生成] 点击
        ↓
读 ref 取会话上下文（延续 v1.7.0：渲染期只存 ref）
        ↓
POST /api/prompt-enhancer/enhance
  { text: idea, mode: 'rewrite', scene, audience, context, libraryItemId? }
        ↓
Host: 若带 libraryItemId，把该条目作为"参考范式"拼进 system
        ↓
返回 { text, ... }
        ↓
结果区渲染 + [复制] [回填]
```

### 5.2 宝库流程

```
面板打开 → 先读内置种子（同步，零延迟）
        ↓
用户点[刷新] → POST /api/wish-tree/prompts { action:'refresh' }
        ↓
Host 拉 raw.githubusercontent.com/.../prompts.csv
        ↓
解析 CSV → 逐条校验 license → 过滤 → 缓存到 profile 目录
        ↓
返回条目列表；失败返回 { ok:false, reason }，Client 保持种子库并提示"离线"
```

### 5.3 降级矩阵（硬要求）

| 失败点 | 行为 |
|---|---|
| 联网失败/超时 | **保持内置种子库**，提示「当前离线，使用内置库」 |
| CSV 解析失败 | 同上，记日志 |
| 许可字段缺失/不在白名单 | 丢弃该条，不整体失败 |
| 结果为空 | 保持种子库 |
| 模型调用失败 | 结果区显示错误，不影响宝库 |
| 上下文读取失败 | 空上下文继续（v1.7.0 已有行为） |

**任何联网路径都不能让面板不可用。**

## 十、风险与对策

| 风险 | 概率 | 对策 |
|---|---|---|
| `sidebar.panellist` 点击不自动切 `main` | **中** | 双入口 + 真机验证；失败则降到 `shell.overlay` |
| `main` slot 是 `shadows-shipped-ui`，注册可能影响会话视图 | 低 | 只用**新 key**（`wish-tree`），不动 `conversation` |
| 10.9MB CSV 解析耗时 | 中 | 不内置全量；种子库取精选 ~60 条；刷新时限制行数 |
| 中文场景下英文种子库价值有限 | 高 | 定位为"结构参考"，生成结果仍由模型用中文产出 |
| 面板体积导致 client.js 过大 | 中 | 面板约 300 行，client.js 预计 950 行，仍可接受 |
| 更名后用户找不到按钮 | 中 | CHANGELOG + 面板内一次性旧名提示 |
