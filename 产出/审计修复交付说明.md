## 过程中的两个额外发现（已一并处理）

1. **`run-tests.mjs` 顶层执行导致 manifest 套件被截断**
   初版 runner 在模块顶层就 `spawnSync` + `process.exit`，`manifest.test.mjs` 一 import 它就递归启动新测试进程并退出，manifest 只报 1 条。已加 `isEntry` main guard，被 import 时只导出纯函数。

2. **`npm test` 在 PowerShell 下不能用 glob**
   `node --test test/*.test.mjs` 依赖 shell 展开，PowerShell 不展开；`node --test test/` 目录形式又会 MODULE_NOT_FOUND。所以发现逻辑放在 Node 里（跨平台）。
